# Quiz-App🧠 

A simple and interactive **Quiz App** built with **HTML**, **CSS**, and **JavaScript**.  
This app displays multiple‑choice questions, tracks the user’s score, and shows the final result at the end.

Perfect for beginners learning DOM manipulation, event handling, and dynamic UI updates.



## 🚀 Features

### 🔹 Core Features
- Multiple questions  
- Four answer options per question  
- Score tracking  
- Next question navigation  
- Final result screen  
- Restart quiz button  

### 🎨 UI Features
- Clean and modern interface  
- Responsive layout  
- Highlighted question and options  



## 📂 Project Structure



quiz-app/ │ ├── index.html ├── style.css └── app.js




## 💻 Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling  
- **JavaScript (Vanilla)** – Quiz logic  

No frameworks required.
